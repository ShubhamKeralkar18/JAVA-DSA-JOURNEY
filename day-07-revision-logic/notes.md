## Q1 - Even Numbers

We use the modulo operator `%`.

If:

number % 2 == 0

then the number is even.

Example:

2 % 2 = 0
4 % 2 = 0
6 % 2 = 0

---

## Q2 - Sum of Numbers

We create a variable:

int sum = 0;

Then repeatedly add numbers to it:

sum = sum + i;

For numbers 1 to 10:

1 + 2 + 3 + ... + 10 = 55

## Q3 - Multiplication Table

5 x 1

5 x 10

## Q4 - Star Triangle

Nested loops are used.

Outer loop controls rows.

Inner loop controls stars.

For:

i = 1 → 1 star
i = 2 → 2 stars
i = 3 → 3 stars
i = 4 → 4 stars
i = 5 → 5 stars

Output:

*
**
***
****
*****

---

## Important Revision

Outer loop = Rows

Inner loop = Work inside each row

if-else = Decision

for loop = Repetition

% operator = Remainder

Nested loop = Loop inside another loop
