# Day 05 - Basic Patterns

## What I Learned

Today I learned and practiced basic patterns using nested loops in Java.

Patterns are created using an outer loop and an inner loop.

The outer loop generally controls the number of rows.

The inner loop controls how many times something is printed inside each row.

# Nested Loop Revision

A nested loop means a loop inside another loop.

Basic structure:

```java
for (int i = 1; i <= rows; i++) {

    for (int j = 1; j <= columns; j++) {
        // code
    }

}
